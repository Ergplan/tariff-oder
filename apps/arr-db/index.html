      How it was built, and how far to trust it

      Method

      1 · Find the orders
      Each commission's tariff-order listing pages were read, and every ARR, true-up, review and multi-year order for a distribution licensee from FY2022-23 onwards was downloaded. Each file is kept with its SHA-256 and its URL.
      2 · Find the ARR tables
      Every page's text layer is split into rows and columns. A table is taken when its printed title names the revenue requirement (“Summary of ARR”, “Aggregate Revenue Requirement approved…”). Tables for only the wires or only the supply business are left out. Scanned pages without a text layer are skipped and counted, not guessed.
      3 · Give each column a meaning
      From the column header: which DISCOM (combined orders print one column group per DISCOM), which year, and whose figure: claimed by the DISCOM, approved by the Commission, an earlier approval quoted for comparison, or actual. Where the header is silent, the table title or the sentence just above it is used, and each value records which of these it came from.
      4 · Keep the evidence
      Every value keeps its printed row label, the page, and the line exactly as printed. A value whose unit is not printed near its table keeps no Rs crore figure. The one exception: three or more of its figures are printed in crore in another table of the same order.
      5 · Measure it
      6 · Ask
      The question box writes one SQL query. It runs in your browser on the same database file, and nothing is sent anywhere. The translator works from fixed rules (no AI model) and lists every choice it made. You can edit the SQL and run your own.

      Limits — read before using a figure

      • Nothing here has been reviewed by a person. Check any figure you use against its page; every row links to it.
      • Commissions define the bottom line differently. Some print a net ARR after non-tariff income, some include the past years' true-up gap, some include carrying cost. The printed label says which, so compare labels before comparing DISCOMs.
      • Coverage is uneven. Many commission websites (Gujarat, Karnataka, Tamil Nadu, Andhra Pradesh, Telangana, Punjab, Haryana, Rajasthan, West Bengal, Assam and others) could not be reached from the build machine. Kerala's order list needs a source the build was not permitted to fetch. These DISCOMs are listed with no data, never with guessed data.
      • Some orders print their ARR tables in layouts the reader does not yet handle, or only as scans. Those orders are listed under Coverage with what was found.
